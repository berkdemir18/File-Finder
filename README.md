# File Finder

File Finder, Windows için geliştirilmiş bir dosya arama ve yönetim uygulamasıdır.

## Yapay Zekâ Kullanımı

Bu uygulama; tasarım, geliştirme, hata ayıklama ve paketleme süreçlerinde yapay zekâ araçlarının desteğiyle geliştirilmiştir.

## Dosyalar

- `File Finder.exe` — Ana uygulama
- `FileFinderService.exe` — Arka plan servisi
- `WebView2Loader.dll` — Microsoft WebView2 bileşeni

## Kullanım

Tüm dosyaları aynı klasörde tutun ve:

`File Finder.exe`

dosyasını çalıştırın.

## Not

Bu depo şu anda kaynak kodu değil, uygulamanın derlenmiş dosyalarını içermektedir.
